# 123 Token Balance

中文、多账号 AI 订阅额度与 API 余额工作台。版本 **1.1.0**，发布目标 Windows 10/11 x64，界面直接使用本地 HAUI 0.1.0 组件与主题。

## 启动

1. 完整解压 `123TokenBalance-1.1.0-win-x64.zip`。
2. 进入同名文件夹，双击 `123TokenBalance.exe`。
3. 点击「网页快速添加」，粘贴能看到订阅或余额的信息页网址。
4. 在独立窗口完成官方登录，打开用量页后点击顶部「一键抓取」。
5. 核对识别预览，补充账号名或套餐名，点击「保存并添加账号」。

已经有 API Key 时可以用「添加账号」选择模板。不会配置时点击「Agent 帮助 → 复制 Agent 提示词」，把提示词交给你自己的 Agent；它生成的 JSON 配置可在本工具预览并导入。

不需要安装 Node、Python、.NET 或额外浏览器运行时。所有 DLL、resources、locales 都是程序的一部分，**请整体移动文件夹，不要只拷贝 EXE**。将文件夹放在当前用户可写的位置。首次启动创建 `data/`，发布包没有任何真实账号或示例账号数据。

## 功能

- 每个账号独立一行；同平台可添加多个账号。
- 展示套餐、5 小时、周、月额度、金额及其他限额；详情保留所有模型窗口和重置时间。
- 缺失字段显示「未提供」，不伪造零值；0 是有效数据。
- 查询失败保留上次成功快照并标记；限流时暂缓刷新。
- 搜索、关注筛选、暂停账号、定时刷新、CSV 导出。
- HAUI 色板、浅色/深色/跟随系统、独立强调色和账号隐私显示。
- 凭据本地加密、口令加密备份、跨电脑导入。
- 订阅页独立登录、一键识别可见额度并生成后续刷新的字段定位。
- Agent 提示词复制、JSON 文件/文本预览与导入。
- 已存 API Key 与请求头可显示、选择复制；可一键复制完整账号记录。
- 账号上/下排序，搜索和筛选时仍按稳定账号身份移动。
- 16 种厂家/模型 Logo 和低透明度背景；图标与背景可分别选库或上传 PNG/JPG/WebP。
- 每行订阅页直达按钮；选中账号行后按 Alt+O，用默认浏览器查看重置、续费等操作。
- 手填订阅日、续费/到期日和提前提醒天数；临期、到期账号进入「需要关注」。

## 1.1.0 操作提示

- **网页刷新**：快速接入保存后保留独立登录窗口。点击刷新会重新加载保存的信息页并读取最新额度；关闭窗口后，从账号菜单打开「登录页面」即可继续。高级连接中可以关闭「刷新时重新加载网页」，以读取当前页面。登录失效时需重新授权。
- **复制记录**：编辑账号，点击「显示」或「显示已保存信息」取回保存的密钥与请求头；「复制全部信息」包含当前编辑值、配置及上次快照，也包含凭据。只向信任的位置粘贴。默认 Agent 提示词不会自动带上已存凭据。
- **Logo**：在「编辑账号 → Logo 与背景」独立设置左侧图标和背景，可调透明度或隐藏背景。上传限制为 4 MB、4096 × 4096 以内，在本机转成最长边 256 px 的 PNG，随账号加密保存。
- **日期**：在「编辑账号 → 订阅日期」填写。月/年周期可给出建议续费日，仍可修改；续费后手动更新日期。提醒只在应用内显示，关闭程序不会后台通知或自动续费。
- **排序与直达**：总览点击「调整顺序」后上下移动。每行的直达按钮和 Alt+O 打开保存的信息页，重置等操作由你在官方页面手动完成。

## 从 1.0.0 升级

1. 先在旧版导出口令加密备份，并关闭旧版和新版。
2. 解压新版到新的文件夹，保留旧版目录。
3. 在同一电脑、同一 Windows 用户下，将旧版完整 `data` 文件夹复制到新版 EXE 旁，再启动新版。不要同时运行两个副本修改同一份数据。
4. 若新版已添加数据，先导出其备份，再决定使用哪份 `data`，不要直接覆盖唯一副本。换电脑或 Windows 用户时使用口令备份导入，并重新网页登录。

本版沿用 schema 1 加密格式，已使用旧版 EXE 创建的隔离测试数据验证 UUID、密钥和请求头兼容。发布包不包含、也不会自动移动你的真实账号数据。

## 平台覆盖与真实边界

共 21 个接入入口：14 个内置 API 适配模板、6 个需要配置字段的网页模板、1 个通用自定义入口。模板数量包含同平台的地区或授权方式变体，**不是 21 家不同服务商**。

内置 API 解析：OpenAI/Codex、Claude OAuth、Claude 网页会话、Gemini Code Assist、DeepSeek、智谱、Z.ai、MiniMax 中国/国际、Kimi Code、Moonshot 中国/国际、硅基流动、OpenRouter。

网页模板：Gemini/Google AI 个人订阅、火山方舟 Agent/Coding Plan、阿里云百炼、腾讯云 Token/Coding Plan、Cursor、GitHub Copilot。可先尝试「网页快速添加」，识别成功后自动生成字段定位；不能识别时，可让 Agent 协助配置 CSS 选择器或有权限的 JSON 查询接口。网页模板不代表已对平台的所有套餐完成自动适配。

通用接入：任意 HTTPS JSON API、静态 HTML、已登录动态网页、明确标记的手动快照。配置说明和样本见 `docs/PLATFORM_GUIDE.md` 与 `examples/`。

一键抓取是本机可见页面识别，支持中英文常见额度文本，不会获取页面没有显示的 API Key、密码或隐藏数据。识别结果需对照官方页面确认；页面改版、图表/iframe、模糊周期以及没有“已用/剩余”标识的数值可能需要人工配置。

订阅额度与 API 充值金额属于不同产品。普通 API Key 不一定能读取 ChatGPT/Claude 网页订阅；OAuth 权限、地区、企业组织选择、平台风控和接口变化都可能影响查询。程序不绕过验证码或登录校验。真实账号未提供，本版真实平台登录后的数字一致性尚未逐平台验证；适配器已通过响应样本与自动化测试。

## 便携数据与密钥

- 账号、API Key、手动 Cookie、附加请求头及快照保存为 `data/accounts.enc.json`，使用当前 Windows 用户的加密服务（DPAPI）保护；`.bak` 为上一份加密备份。
- `data/runtime/` 包含应用主题与各账号独立的浏览器会话。
- 同一电脑、同一 Windows 用户下可以整体移动文件夹。换电脑或 Windows 用户时先在旧电脑导出口令备份，在新电脑导入；网页登录需重新进行。
- 口令备份 `.tbb` 使用 scrypt + AES-256-GCM，包含 API 凭据，不含浏览器 Cookie 数据库。口令至少 10 个字符。
- 导入新增账号，不覆盖现有账号。API 快照清空并重新查询；手动快照保留原始采集时间。
- CSV 含账号标识和额度，不含密钥或请求头。分享程序前请勿包含自己的 `data/`。
- 账号配置损坏或不可解密时进入保护性只读模式，不自动覆盖原文件。请先完整复制 data 留档；可从能读取的旧机器导出口令备份恢复。
