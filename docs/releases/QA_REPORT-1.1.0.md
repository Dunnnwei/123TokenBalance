## 验证限制

1. **真实平台**：未提供真实凭据，没有逐平台完成官方登录、各套餐数字和重置时间核对。一键抓取依据可见 DOM 的通用规则，不能承诺任意网址均可自动接入；页面没显示的 API Key 或信息不会获取。内置 API 测试为公开格式及固定样本，网页流程测试为可控页面。
2. **授权与网页变化**：令牌过期、地区、组织、验证码、内嵌浏览器限制、代理、动态 iframe/图表及页面改版仍可能需要用户授权或调整字段。工具不绕过这些限制，不读取其他浏览器的会话。
3. **机器和系统覆盖**：未在另一台机器、独立 Windows 10、不同 GPU、多显示器或实际 Windows 125%/150% DPI 下验收。备份导入和跨版本读取已在当前机器验证，跨电脑物理迁移未执行。
4. **签名与杀软**：EXE **未签名**，没有发行者证书。未执行商业杀软、VirusTotal 或 SmartScreen 信誉测试；本次 Defender 未发现威胁，不代表所有杀软零误报。
5. **自动化与提醒**：默认浏览器直达验证的是正确系统 API 和参数，未操作真实网站的重置按钮。日期提醒只在程序内展示，不是后台通知。axe 仅覆盖总览自动规则，不代表全应用人工读屏验收。

本版继续采用普通便携目录，不使用 UPX、混淆壳、自解压启动器、管理员提权、驱动、进程注入、后台服务或开机自启。关闭主窗口退出程序。便携使用需整体移动文件夹，不应只复制 EXE。
