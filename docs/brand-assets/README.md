# 平台 Logo 来源

本版本的厂家/模型 Logo 来自开源项目 [Lobe Icons](https://github.com/lobehub/lobe-icons)，静态 SVG 包 `@lobehub/icons-static-svg@1.95.1`。所用文件及其 SHA-256 见 sources.json，项目 MIT 许可全文见 LICENSE-lobe-icons.txt。厂商品牌标识的商标权属于各自权利人，仅用于辨认用户自己的账号，不表示官方合作或背书。

只挑选需要的静态 SVG 随程序分发，运行时不访问图标 CDN。单色图形在深色主题下使用当前前景色；行背景采用低透明度遮罩，不修改品牌图形路径。未知自定义平台使用通用图形。
