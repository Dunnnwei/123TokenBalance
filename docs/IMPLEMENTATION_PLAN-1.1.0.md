# 123Token 1.1.0 迭代方案

本方案在 1.1.0 业务代码修改前留档。沿用本地 HAUI 组件体系与普通 Windows x64 便携目录分发。

## 八项需求与实现

1. **订阅页面快速接入**：新增「网页快速添加」。输入订阅信息页 HTTPS 地址即可打开带可信地址栏和「一键抓取」按钮的独立登录窗口。用户完成官方登录后，程序仅在点击时读取当前可见页面，自动识别平台、可见账号、套餐、5 小时/周/月/日额度及账户金额，并生成可重复刷新的字段定位。主窗口展示识别结果和原文供确认，用户可以补充账号名后保存。未识别、含义不明确的数值不猜测；网页方式使用会话，无需填写 API Key。页面不显示的密钥不尝试挖取。
2. **Agent 指导与配置**：提供「复制 Agent 提示词」，包含网址、平台等非敏感上下文，以及可导入 JSON 格式、字段语义和验证要求。增加粘贴/选择 JSON 配置文件、预览、导入流程，使用户自己的 Agent 能实际完成配置。提示词不自动包含密钥、Cookie 或请求头。导入始终创建新账号，不覆盖现有记录。
3. **显示和复制记录**：修复已保存 API 凭据被脱敏后无法显示的问题。使用仅可信主窗口可调用的显式读取入口；支持凭据复制、附加请求头显示、复制完整账号 JSON。保留未保存编辑值，列表继续脱敏；所有复制动作由用户按钮触发。
4. **账号排序**：增加「调整顺序」和每行上/下移动。按稳定账号 UUID 对相邻可见行交换位置，隐藏行不变；持久化到原账号数组，刷新结果仍按 UUID 更新，重启/备份保留顺序。
5. **品牌辨识**：以随包分发的厂家/模型 SVG Logo 替换首字母块；在行内容后设置低透明度品牌水印。背景不接收点击、不影响复制与读屏，文字层保持前景；浅色和深色分别校验。自定义未知平台使用通用图形。
6. **用户补充：自定义 Logo**：账号 Logo 与背景 Logo 分别提供内置库选择和本地 PNG/JPG/WebP 上传。上传图像在本机解码并归一为小尺寸 PNG，不加载外链或任意 SVG 脚本；随账号加密保存和备份迁移。背景透明度可调整，可单独隐藏。
7. **用户补充：直达订阅页**：每行提供默认浏览器直达按钮，聚焦该账号行后可按 Alt+O。使用账号保存的信息页链接，保留 SPA 的 hash 路由。快捷键仅在本工具主界面生效；重置次数查看和重置操作由用户在官方页面手动执行，工具不提交重置请求。
8. **用户补充：订阅日期**：增加手动订阅日期、续费/到期日期、按月/按年/自定周期以及提前提醒天数。可按日历周期生成建议续费日，月底和闰年日期正确钳制；用户可修改。列表与详情显示，临近续费和过期加入「需要关注」。提醒只在程序中展示，不引入后台常驻或系统计划任务。

## 安全与兼容

- 旧版 schema 1 数据继续使用，不改变 DPAPI、加密备份和独立账号分区契约。1.0.0 发布物保留。
- 远程页面没有 Node、preload、主程序 IPC 或设备权限；可信工具栏和远程网页使用不同 WebContents，网页不能伪造抓取按钮。抓取数据仅供本机解析，不发送至远程 Agent/LLM。
- 不使用调试器注入、全局浏览器 Cookie 读取、压缩壳、管理员权限、自解压包装、后台服务或开机自启。普通应用内部 DOM 读取不执行页面提供的代码。
- 解析限制页面节点/文本量，排除输入框、脚本、隐藏元素和密码。百分比需辨别已用/剩余；不把套餐价格当余额，不把日额度误认为 5 小时。
- 未提供签名证书，继续明确 EXE 未签名，完成本地 Defender 扫描但不承诺所有杀软零误报。

## 验收矩阵

| 需求 | 必须验证 |
|---|---|
| 快速接入 | 中英文页面、已用/剩余、零值、金额、套餐识别；无额度页面失败；UI 输入网址→窗口→抓取→预览→保存→刷新；独立会话 |
| Agent | 复制提示词不含已存密钥；JSON 校验/文件导入、错误提示、导入新增 UUID |
| 显示复制 | 保存密钥后重启编辑可显示/复制；附加头读取；清除/未保存修改不被旧值覆盖；主窗口以外不能读取 |
| 排序 | 上下移动、过滤行、重启、异步刷新、旧数据升级 |
| Logo | 本地资产/来源许可、明暗截图、文本对比度、点击及窄窗口 |
| 自定义 Logo | 图标与背景独立选择/上传、透明度、重启与加密备份保留 |
| 订阅页直达 | 每行按钮与 Alt+O 调用默认浏览器，保留 hash 路由 |
| 订阅日期 | 日历月与闰年、手动改期、临期/过期关注、列表/详情和重启保留 |
| 交付 | 当前源码测试、正式 EXE 测试、目录移动、Defender、版本目录/ZIP/哈希/许可证/验收记录 |

目标版本 1.1.0。验收仅报告实际执行的层级；真实平台登录与数字核对仍需用户自己的账号。
