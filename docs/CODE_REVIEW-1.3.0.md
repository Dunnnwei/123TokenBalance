## 安全与数据边界

- 原有 IPC 主窗口/抓取工具栏来源和 frame 校验保持；远程网页无 preload/Node，sandbox、contextIsolation、webSecurity 保持启用。采集代码只读取本地编写的 DOM 逻辑，不解释网页指令。
- 页面只允许 HTTPS；读取前后校验 origin 和跳转。明确登录页、401/403 提示人工登录/验证；不自动反复尝试无效授权，不绕过验证码。
- Cookie 和 localStorage 留在本工具独立持久 partition；合并更新 UUID 时显式保留该抓取会话引用。导入备份去掉引用，避免新 UUID 串用旧账号会话。清除、删除和重新登录使用实际 partition。
- 按 UUID 合并同一账号任务，三账号并发；网络/超时或 502/503/504 最多重试一次。结果提交仍受 revision 校验，迟到请求不复活删除项。
- 不读取其他浏览器、CLI 或其他软件凭据。实际账号验证使用用户本工具数据的隔离副本，只输出匿名结构与成功/失败分类；检查原配置文件摘要未变化，测试副本在关闭后删除。真实账号内容未进入截图、源码或发布包。
- 无安装服务、启动项、提权、加壳或安全排除设置。发布沿用原生静态启动器、完整 Electron 目录及验证更新路径。
