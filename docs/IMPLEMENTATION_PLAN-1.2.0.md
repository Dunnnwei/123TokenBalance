# 1.2.0 实现方案与验收矩阵

日期：2026-10-19。用户授权本轮实现、选择版本号、建立 GitHub 仓库并发布。

## 目标与现状

用户反馈另一台 Windows 11 电脑复制完整文件夹后双击无任何窗口，等待半小时仍无提示。当前不能接触该机器，因此不能把某一种原因宣布为已证实根因。源码可确认旧版隐藏主窗口直到 ready-to-show，启动过程没有独立诊断、超时或完整日志；数据目录不可写会直接退出；复制机器绑定的 Chromium/DPAPI 状态存在兼容与恢复问题。

当前 1.1.0 是 Electron 44.9.0 的普通 x64 目录包，自带 Chromium/Node，不依赖外部 Node、Python、.NET、WebView2。PE 检查显示没有直接依赖 VC Redistributable。保留现有账号功能、schema 1、主题、凭据保护与发布目录约定，不盲目要求用户安装无关运行库。

## 实现结构

1. **独立原生启动器**：根目录 `123TokenBalance.exe` 改为 Win32 C++ 小型可执行文件，静态链接 CRT，内核系统 API 即可运行；Electron 主体更名为 `123TokenBalance.App.exe`。立即显示启动检测窗，检查 Windows 版本/架构、运行文件存在与大小、数据目录可写性、机器绑定的浏览器密钥、系统媒体组件，提供明确需求、官方链接和日志。检测失败时保留可见结果；主体异常退出或 45 秒内未完成 UI 加载时显示可诊断错误。不使用脚本策略绕过或提权。
2. **兼容启动**：主进程默认关闭硬件加速以降低跨 GPU 空白/崩溃风险；立即显示窗口加载状态；在主界面加载完成后通知启动器。启动与渲染失败落盘并显示。不可写安装目录使用当前用户 LocalAppData 数据位置，并在界面明确实际路径。保留旧版 Local State 中的密钥，不在同机迁移时重建密钥。跨机无效浏览器配置只归档不删除。
3. **环境与迁移界面**：每次启动执行本地快速检查，不把联网检查作为启动条件。侧栏显示结果摘要，偏好设置可展开检查项目、路径和官方帮助。不可解密账号保留只读保护，并提供明确的归档恢复操作；恢复前保存原始加密文件，允许导入口令备份，不能把换机失败当作明文存储的理由。
4. **GitHub 发布**：在授权账号下创建 `123TokenBalance` 公开仓库，源代码采用白名单提交，Release 存放便携 ZIP、校验和、验收记录与发布说明。公开仓库用于无需凭据的应用更新。用户提供的 token 仅在本次发布进程内读取，不进入仓库、程序、日志或命令行参数。
5. **应用更新**：界面提供“检测新版本”和仓库下载入口。只查询固定仓库稳定 Release；验证语义版本、唯一资产、下载地址和 GitHub SHA-256 digest。用户点击“下载并更新”后流式下载，限制时间/大小，显示进度，安全解压到同磁盘临时兄弟目录，验证完整文件哈希。拒绝路径穿越、绝对路径、符号链接、重复路径、数据夹、缺失清单、超大解压内容与校验失败。
6. **安装与恢复**：普通原生辅助进程等待主程序退出后切换目录，保留整个旧版为备份，移动原 data；外部 data 继续使用原路径。切换失败恢复旧目录；新程序启动未通过握手则回滚并提示。仅操作已验证的应用目录，不改系统设置、不强制终止无关进程、不安装服务。下载/校验失败不退出旧程序。
7. **代码与误报检查**：复核 IPC 权限、URL 与重定向、升级信任边界、归档路径、数据恢复、文件操作。运行生产依赖审计和本机 Defender；记录真实扫描结果。保留源码、普通目录、静态原生启动器、asInvoker，不做加壳、混淆、自解压、不禁用安全防护。未提供发行者签名证书，不能承诺任何杀软绝不误报或消除 SmartScreen。

## 验收矩阵

| 项目 | 验收方式 | 通过条件 |
|---|---|---|
| 原生依赖 | PE 导入表 + 限制 PATH 启动 | 无外部开发运行库，缺件有可读结果 |
| 启动 | 正常/缺文件/损坏尺寸/不同工作目录/中文空格路径 | 有可见反馈、日志和就绪握手，无无限隐藏等待 |
| 便携与数据 | 同机整体移动、旧版加密数据、跨机密钥失效模拟、只读目录 | 保留账号密钥或提供无损恢复，不覆盖不可读原文件 |
| 环境 UI | 正式包桌面自动化 | 每次显示检查摘要与详情，失败有处理说明/链接 |
| 更新解析与安全解压 | 单元及集成样本 | 正常稳定版可用，错误来源/摘要/路径/包均拒绝 |
| 更新安装 | 隔离副本完整更新、失败回滚 | data 保留、版本切换、旧版可恢复，无外部目录写入 |
| 回归 | TypeScript、单元、正式 Electron 桌面用例 | 原有功能通过，新增功能证据留存 |
| 发布 | ZIP CRC/全文件哈希/匿名 GitHub 下载 | 目录无 data/token，远端下载与本地哈希一致 |
| 安全扫描 | npm audit + Defender + 源码复核 | 记录结果和未验证范围，不把静态检查等同全部杀软认可 |

## 交付约定

沿用 `发布/123TokenBalance-1.2.0-win-x64/` 与同名 ZIP、`SHA256SUMS-1.2.0.txt`、`release-validation-1.2.0.json`、版本扫描日志、发布说明。旧版本保留。当前目录原无 Git，先对现有源码建立本地基线，再提交本轮变更。实际远端地址与测试证据在发布完成后写入 README 和 QA 报告。

## 验证边界

可验证当前电脑、模拟故障、隔离副本和 GitHub 真实发布。另一台用户电脑、全部 Windows/GPU、其他商业杀软和 SmartScreen 信誉仍需明确标注未实测。
