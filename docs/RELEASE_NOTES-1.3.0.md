# 123 Token Balance 1.3.0

日期：2026-10-21。Windows 10/11 x64 完整便携目录。

本版修复网页登录窗口关闭后无法刷新、重新抓取产生重复账号、仅余额更新掩盖其他用量缺失的问题，新增原账号恢复入口与明确重置时间展示。

- 关闭网页或重启程序后，刷新会在后台恢复本工具内的独立持久会话，等待动态数据加载。网络/超时与 502/503/504 最多重试一次；平台要求登录或验证时提示人工处理。
- 账号详情、编辑及菜单中点击「程序内打开并重新抓取」，登录、核对后「更新原账号」，保留原 UUID、名称、顺序、Logo 和订阅日期。首页抓取也可选择更新已有账号，检测到明确邮箱不一致或账号被修改/删除时拒绝覆盖。
- 自动抓取账号按页面语义重新识别，原有关键周期缺失则保留整份旧快照和原采集时间，详情明确标注旧数据。高级 CSS 映射仍可手工配置。
- 5 小时重置时间和周刷新日在总览与详情展示。采用接口时间、网页明确时区时间及明确倒计时；时间已到提示刷新确认。无时区/含糊时间显示未提供。
- Kimi 月度共享额度、5 小时用量与余额分别处理；新套餐没有周限额时不编造周用量，未知 API 总额度周期也不假定为周。

## 更新方式

推荐在原版点击「检测新版本 → 下载并自动更新」。更新器验证 GitHub 摘要和 ZIP 内逐文件哈希，再保留原数据、切换完整目录并检查启动。也可以从 GitHub 下载 ZIP，完整解压后按 README 迁移同机数据。

日常路径 `D:\Program Files\123TokenBalance` 可以继续使用；升级前可先在程序内导出 `.tbb` 口令备份。请关闭旧程序，再手动替换完整程序文件，保留原实际 `data` 目录。若环境检测显示实际数据位于 LocalAppData，请按显示的位置处理，不要误建一份空配置。不要只复制 EXE，不要覆盖或删除自己的数据。

启动公开入口为根 `123TokenBalance.exe`，`123TokenBalance.App.exe` 是内部主体。发布 ZIP 不含个人数据。
