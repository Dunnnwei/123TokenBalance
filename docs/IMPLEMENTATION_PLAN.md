# 123 Token Balance v1.0.0 实现方案

日期：2026-10-18（Asia/Shanghai）。此方案在业务代码开发前建立。

## 已确认需求

- 中文 Windows 10/11 x64，免安装便携目录，双击 EXE；发布目录同时提供带版本号的程序文件夹与 ZIP。
- 每个账号拥有独立 UUID；同一平台可以添加任意多个账号，每个账号占一行，身份不依赖表格索引。
- 填写平台网址、账号标识、API Key、信息页面地址；按需填写 Cookie、OAuth Token、请求头和字段映射。
- 优先覆盖 OpenAI/Codex、Claude、Gemini、DeepSeek、智谱、MiniMax、Kimi、火山方舟；范围不止八个平台。
- 未知平台可通过通用 JSON、静态 HTML 或已登录的动态网页接入；无法自动读取时提供明确标记的手动快照。
- UI 直接使用 D:\DiskWork\PJ\HAUI 的本地 HAUI React 组件包、字体、主题、色板和交互配置，不另造设计系统。
- 降低杀软误报：普通目录分发，无 UPX/混淆壳/自解压加载器、无提权/驱动/注入/开机常驻。

## 架构和决策

采用 Electron + React + TypeScript。HAUI 原生提供 React 组件，因此使用 Electron 容纳原组件；替代最初调研阶段的 .NET 原生控件方案。Electron 附带 Chromium 和 Node，最终用户无需安装运行时。

- renderer：HAUI ThemeProvider、Button、Input、Select、SearchField、Dialog、ConfirmDialog、Loader、Progress、图标与字体；扁平表格工作区，独立色板、明暗和强调色设置。
- preload：白名单 IPC API；不向页面开放 Node、文件系统或通用 IPC。
- main：账号仓库、凭据加密、请求执行、平台解析、浏览器账号会话、定时刷新、备份导入导出。
- core：可测试的纯数据模型、字段映射、平台适配、校验、请求策略、可移植加密备份。
- data：可执行程序旁的 data 文件夹。敏感字段使用 Electron safeStorage（Windows DPAPI）加密；网页会话独立分区。

## 统一数据口径

每行显示平台和账号、订阅级别、5 小时额度、周额度、月额度、账户金额/其他额度、查询状态和最后成功时间。详情显示所有额外窗口、单位、重置时间和来源。

额度记录包含周期、剩余值/总额或剩余百分比、单位和重置时间。金额按币种展示，不把人民币与美元相加。缺失和不支持显示「未提供」，0 是有效数值。日额度保留为日额度，不塞进 5 小时。平台不返回套餐名称时允许用户填写并标记来源，不根据金额或请求数猜套餐。

网络失败保留最后成功快照并标记「旧数据」；认证失败明确提示重新授权。编辑凭据/身份后清除旧快照以防串号；所有异步返回以账号 UUID 与配置修订号核验。刷新去重、并发限制、超时和 429 冷却；界面先打开，数据后台加载。

## 通用平台接入

1. JSON API：HTTPS 查询地址、GET/POST、Bearer/API-Key/Cookie/浏览器会话/无认证、附加请求头、可选 JSON 请求体。
2. 字段映射：JSON 路径或 CSS selector，套餐字段和多条额度映射；支持已用百分比、剩余百分比、已用/总量、剩余/总量、金额和纯数值。无脚本执行、无 eval。
3. HTML：从 HTTPS 响应解析 selector 文本。
4. 动态网页：用户主动打开每账号隔离的登录窗口，完成官方登录；读取指定网页元素。远程页无 preload，无 Node，无权限授予；不扫描本机浏览器凭据。
5. 手动快照：作为显式人工录入方式，保留采集时间与来源，不伪装成 API 实时数据。

网页地址与查询 API 地址分别保存；普通网页链接不能被假定成 JSON API。自定义目标在保存表单中可见，禁止明文 HTTP、带用户名密码的 URL、危险协议和跨域自动重定向携带凭据。

## 安全与便携

主窗口仅加载打包的本地资源，CSP 禁止联网，sandbox/contextIsolation 开启。任何远程登录窗口只允许 HTTPS 浏览，禁止自动下载和权限请求。外链经过协议验证，由用户操作后打开。日志不存储原始响应、API Key、Cookie 或请求头。

DPAPI 凭据仅当前 Windows 用户可解密；同机移动文件夹继续可用，换电脑重新登录或使用口令加密备份迁移。备份采用 scrypt + AES-256-GCM，需用户输入口令，默认不包含浏览器 Cookie；导入先校验再添加新 UUID，避免覆盖现有账号。浏览器会话不可宣称跨机可用。

无代码签名证书，最终 EXE 如未签名必须明确报告；无法承诺所有杀软零误报。提供 SHA-256、依赖许可证、构建记录和可用的本机安全扫描结果，不要求关闭杀毒软件或添加全局排除。

## 验收矩阵

| 需求 | 验收证据 |
|---|---|
| 同平台多账号独立 | CRUD、刷新并发、删除/编辑期间过期响应测试 |
| 配置平台/网址/账号/密钥/信息页 | 表单 UI 自动化、持久化重启验证 |
| 周期正确、0/缺失可区分 | 固定 API 响应样本单元测试；不同周期不混用 |
| 自定义平台无需改代码 | 自定义 JSON 与 HTML 映射测试、动态网页读取 UI 流程 |
| 密钥不以明文落盘 | 持久化检查、备份认证/错误口令测试 |
| HAUI 实际复用 | 本地包依赖与许可、明暗截图和键盘流程 |
| 错误可恢复 | 401/429/网络失败、旧数据标记、坏配置与损坏存储测试 |
| 便携可运行 | 发布 EXE 启动、无系统 Node 依赖、移动目录启动 |
| 发布完整 | 版本目录、ZIP、README、CHANGELOG、SHA256、QA 报告 |

真实账号凭据未提供，平台适配以公开接口资料和响应样本验证；真实联网登录后的额度一致性必须单独标记，不能用样本测试代替。
