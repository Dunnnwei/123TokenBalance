## 三轮体验测试

方式是自动桌面交互与截图复核，不是邀请三位真人测试，也不是持续数天/跨周观察。第一、二轮初测后修复问题，再在第三轮正式程序完整回归中复验全部相关路径。

### 第一轮：恢复与账号合并（4 条主要路径）

1. 页面抓取后关闭网页，刷新通过后台页面获得变化值；重启程序后持久 Cookie 与 localStorage 仍可读取；后台临时窗口用完释放。
2. 点开原账号 → 程序内打开并重新抓取 → 更新原账号；记录数量不增，UUID、顺序、原备注、Logo、订阅保持。
3. 首页抓取识别到唯一相同邮箱，确认更新原记录；保存新的独立会话引用，关闭网页与重启后仍使用该会话。
4. 编辑窗口有直接恢复操作，可到达绑定原账号的抓取确认。

### 第二轮：失败与持续使用（6 条主要路径）

1. 延迟 1.8 秒出现的 DOM、改变的结构与 CSS 定位仍能重新识别；后续缺少周用量时保留整份旧快照和原时间。
2. 登录页替代用量页时显示恢复入口，不用登录页面数值覆盖旧用量。
3. 抓取到不同邮箱时拒绝更新；原账号期间被编辑/删除时拒绝迟到保存。
4. 清除会话后后续刷新不能继续读取已删除的登录状态。
5. 两个账号以不同 Cookie 值执行五轮并发刷新及重启，结果保持隔离，无残留后台窗口。
6. 临时 HTTP 503 自动恢复一次；持续故障停止重试，保留成功快照。授权错误和限流不进入该重试循环。

复核修复了实际页面的两类误判：把“完全重置（每周 + 5 小时）”操作当用量，以及把“本周期消费”当余额。另纠正 Kimi 未声明周期的总额度默认为周的旧行为。

### 第三轮：正式包全量回归（31 项）

正式目录程序执行所有旧功能及新路径：创建/删除/复制、凭据显隐与复制、动态/JSON/HTML/手工解析、Agent 导入、排序、Logo、订阅日期、备份、默认浏览器直达、主题、无障碍、恢复、网页安全隔离、版本检测、错误下载和换机保护。

专项确认 940×760 深色界面、滚动确认与键盘更新按钮，以及实际 1.2.0 加密配置升级。原生启动器额外执行 9 个生命周期场景，避免仅验证 Electron 主体而遗漏公开 EXE。

机器可读用例清单：`docs/verification/1.3.1/ux-three-rounds.json`。截图：`docs/screenshots/1.3.1/`。

## 真实账号只读核对

用户提供的日常目录为 `D:\Program Files\123TokenBalance`。本轮使用其本工具数据的隔离副本刷新，原始账号主文件及备份文件 SHA-256 前后相同；未替换日常程序，未更改平台账号、套餐或密钥。

- 7 个账号中 6 个完成当次真实刷新；一个自定义 JSON 账号仍由平台返回授权失效，保留旧数据，需要用户重新登录或更新原凭据。
- 原 Codex 网页会话可在无可见网页窗口时恢复，5 小时/周用量与两种中文倒计时均得到识别。
- 原 Kimi 仅有余额映射；当前识别到月度共享额度、5 小时用量与余额。实际页面没有明确周窗口；官方当前新套餐也不设周限额，因此不编造周数据。
- 智谱接口当次返回 5 小时及周窗口的明确重置时间。Kimi 网页日期未注明时区，本版保留「重置时间未提供」。

这里只能证明当次、同机、现有有效登录下的真实读取，不能证明平台以后不会撤销 Cookie/Token。原账号标识、余额、凭据、Cookie、原始页面和私有日志未进入截图或发布包。

## 重置时间可行性与接受边界

接口的绝对时间、网页带明确时区的 ISO 时间及明确相对倒计时可稳定落到采集时刻。页面只有“周五 10 点”、无时区日历日期、图形中不可读取的文案或没有该窗口时，不推算。到期后显示待刷新确认，不擅自恢复满额，也不自动将日期增加 5 小时或 7 天。

官方规则来源见平台指南末尾。Kimi 新旧套餐规则已按当前官方文档核对；不同账号和未来改版仍需以平台真实返回为准。

## 未完成的外部验收

没有真实连续多日/跨周观察；没有物理第二台电脑、Windows 10/ARM64、完整 GPU/DPI、读屏软件、发行者证书、SmartScreen 信誉或其他杀软/VirusTotal 验收。本机 Defender 通过仅代表本次扫描。跨机网页登录仍需重新授权，短期 API/OAuth Token 不会被本工具自动延长或绕过。

升级使用原版「检测新版本」自动更新，或完整解压目录并保留实际数据目录；不要只复制 EXE。既有重复行本轮未自动删除，以免误删有独立配置的账号。

## 1.3.1 追加与旧版升级限制

在 1.3.0 最终发布检查时，真实旧版 1.2.0 发现新版本成功，但解包 ASAR 失败，不能把该测试报为通过。1.3.0 Release 已撤回草稿，最终交付 1.3.1。更新解包局部采用 original-fs，新增真实正式 Electron 有效 ASAR 用例（旧实现失败、新实现通过），正式回归增至 31 项。旧版 1.2.0 无法通过尚未完成的更新获得修复，必须手动升级一次。此后更新能力按本版实际回归与 GitHub 证据记录，不承诺旧版自动安装成功。
